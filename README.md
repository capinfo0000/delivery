# TikTok コメント読み上げ（スマホ用）

TikTok LIVE のコメントを、スマホで**リアルタイムに音声読み上げ**するアプリです。

## 現状まとめ（3つの提供形態）

用途に応じて3系統を用意しています。どれもコメント取得は中継サーバー(Socket.IO)経由で、
音声読み上げは無料・回数無制限です。

| 形態 | 置き場所 | iPhone1台で背面読み上げ | ビルド状況 |
|---|---|---|---|
| **① Webアプリ**（ルート直下） | GitHub Pages / コアサーバー等 | ✗（別端末 or 前面表示で使用） | 不要（ブラウザで動作） |
| **② Capacitor版**（ルート＋`IOS-APP.md`） | iPhone（SideStore無料導入） | △（要実機確認） | ✅ IPAビルド成功 |
| **③ React Native + Expo版**（`mobile/`） | iPhone（SideStore無料導入） | △（要実機確認・背面音声に注力） | ✅ IPAビルド成功 |

- **手軽さ重視** → ①Webアプリ（＋別端末読み上げが確実）
- **iPhone1台で完結したい** → ②/③ を SideStore で無料インストール（Mac不要・審査不要）
  - IPAは GitHub Actions が自動生成（`ios-build.yml` / `mobile-ios-build.yml`）
  - 背面読み上げの継続性は iOS 実機での最終確認が必要
- ネイティブ導入の詳細手順 → [IOS-APP.md](./IOS-APP.md)、RN版は [mobile/README.md](./mobile/README.md)

> ⚠️ 既存サービス **TikFinity**（スマホアプリ版あり）でも同等のことが可能です。
> 「まず試す」なら既存サービス、「無料・回数無制限・完全カスタマイズ」なら本自作、と使い分けられます。

---

以下は **①Webアプリ** の説明です。
アプリのインストールは不要で、ページを開くだけで使えます。

## できること

- TikTok LIVE のコメントをリアルタイム受信して日本語で読み上げ
- 速さ・高さ・音量・音声（声）の調整
- 投稿者名の読み上げ ON/OFF
- **ギフト・フォロー・シェアの読み上げ＋効果音**（効果音はアプリ内生成で外部ファイル不要）
- 絵文字・URL の読み飛ばし、長すぎるコメントのカット
- 混雑時に古いコメントを飛ばして「今」に追いつく
- 接続なしで試せるデモモード
- ホーム画面に追加してアプリのように起動（PWA）

## iPhoneアプリ化（無料・1台で裏読み上げ）

「iPhone1台で、TikTokを見ながら裏で読み上げ」したい場合は、ネイティブアプリ化できます。
**Mac不要・Apple Developer（年¥15,000）不要**の無料ルートです。手順は **[IOS-APP.md](./IOS-APP.md)** を参照。

ざっくり：GitHub Actions（無料macビルド）で IPA を生成 → Windows の SideStore で
無料Apple IDインストール。ネイティブ音声合成＋バックグラウンド音声で裏読み上げします。

ネイティブ実装は2系統あります（どちらも同じ無料サイドロード方式）:
- **Capacitor版**（今のWeb画面を流用）… ルート直下 + `IOS-APP.md`
- **React Native + Expo版**（作り直し・背面音声に注力）… `mobile/` + `mobile/README.md`

## しくみ（重要）

ブラウザから TikTok へ直接コメントを取りに行くことはできません（CORS・署名の制限）。
そのため、間に **TikTok チャット中継サーバー** を挟みます。

```
TikTok LIVE  ──→  中継サーバー(Socket.IO)  ──→  このWebアプリ(スマホ)  ──→  音声読み上げ
```

- 既定では公開の中継サーバーに接続するので、**あなたがサーバーを動かす必要はありません**。
- ただし公開サーバーは混雑・停止・制限の可能性があります。安定させたい場合は
  [TikTok-Chat-Reader](https://github.com/zerodytrash/TikTok-Chat-Reader) を自分で立て、
  アプリの「サーバー設定」にその URL を入れてください。

## 使い方

### 1. ページを公開する（GitHub Pages・無料）

このリポジトリの設定で GitHub Pages を有効にします。

1. GitHub のリポジトリ → **Settings → Pages**
2. **Build and deployment** の Source を **Deploy from a branch**
3. Branch を `claude/tiktok-comment-tts-eye7ai`（または `main` にマージ後 `main`）、フォルダを `/ (root)` にして Save
4. 数分後に表示される URL（例: `https://<ユーザー名>.github.io/delivery/`）をスマホで開く

### 2. スマホで操作する

1. 一番上の「**🔊 読み上げを開始**」を一度タップ（iPhone/Android で音声を有効化するために必要）
2. 「① 配信に接続」に配信者のユーザー名（例: `@tiktok`）を入れて「接続」
3. コメントが流れると順番に読み上げられます

まず動作だけ試したいときは「🧪 デモ（接続なしで試す）」を押してください。

## リアルタイム性について

- コメントは届いた順にキューに入り、**前の読み上げが終わると次が読まれます**。
- コメントが速すぎて読み上げが追いつかない場合は、設定の
  「混雑時は古いコメントを飛ばす」と「待機キューの上限」で、最新に追いつくよう調整できます。
- TTS の性質上、同時に複数を同時発話はできず1件ずつ読みます。

## おすすめの使い方：2台構成（iPhoneでTikTokを見ながら聞く）

iPhone では、TikTokアプリを開いている間にブラウザを裏で動かして読み上げ続けることが
**できません**（iOSの仕様。ブラウザは裏に回ると音声合成が止まります）。

そこで、**端末を2台に分ける**のが確実でおすすめです。

```
[iPhone]  TikTok アプリで配信／視聴（画面はこちら）
[別の端末] このWebアプリを開いて読み上げ（古いスマホ・タブレット・PCなど）
```

手順：

1. このアプリのURLを、読み上げ役の**別端末**で開く
2. 「🔊 読み上げを開始」をタップ → 配信者のユーザー名を入れて「接続」
3. iPhone では普通に TikTok を見る／配信する
4. コメントは別端末のスピーカーから読み上げられます

ポイント：

- コメント取得は中継サーバー経由なので、**iPhone側でTikTokを開いているかどうかとは無関係**に動きます。
  別端末だけで配信のコメントを受け取れます。
- 読み上げ役の端末は、画面を点けたまま・スリープしない設定にしておくと安定します。
- イヤホン/スピーカーは読み上げ役の端末につなぎます（自分の配信に音を入れたくない場合はイヤホン推奨）。

## 注意（1台のiPhoneだけで使う場合）

1台のiPhoneだけで使うときは、このアプリを**前面に表示している間だけ**読み上げます。
画面ロック中・他アプリ（TikTok等）に切り替え中は、iOSの仕様で読み上げが止まります。
「見ながら裏で読み上げ」をしたい場合は上記の2台構成をご利用ください。
